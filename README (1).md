# Customer Support Ticket Classification

## Project Overview
This project uses Machine Learning to classify customer support tickets into categories based on their text.

## Models Used
- Logistic Regression
- Linear Support Vector Machine (Linear SVM)

## Workflow
1. Load and explore the dataset.
2. Clean the ticket text and handle missing or empty values.
3. Convert text into numerical features using text vectorization.
4. Train and evaluate the classification models.
5. Compare model performance using accuracy, precision, recall, and F1-score.
6. Use the trained model to predict the category of a new ticket.


## Technologies Used
- Python
- Pandas
- scikit-learn
- NLP / text classification
- Jupyter Notebook

## Run the Project
1. Clone or download this repository.
2. Install the required packages:

   ```bash
   pip install pandas scikit-learn jupyter
   ```

3. Open the notebook and run the cells in order.
